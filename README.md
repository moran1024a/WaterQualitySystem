# WaterQualitySystem（海水养殖水质数据分析系统）

本项目为 C11 课程设计实现，面向海水养殖场景，提供从原始 CSV 数据读取、预处理、统计分析、预警分析、线性回归预测到报告输出、登录权限与备份恢复的完整流程。

## 1. 编译与运行

```bash
make gcc
./WaterQualitySystem
```

清理：

```bash
make clean
```

## 2. 默认账户

- 管理员：`admin / 123456`
- 访客：`guest / guest`

## 3. 目录结构

- `include/`：头文件与公共数据结构
- `src/`：模块实现
- `data/`：原始数据与用户文件
- `output/clean/`：清洗数据输出
- `output/reports/`：报告输出
- `backups/`：备份文件

## 4. 功能模块

1. 文件读取与存储：CSV 动态读取、二进制读写、随机记录读取、存储对比。  
2. 数据预处理：缺失值识别与填充、异常值处理、移动平均滤波。  
3. 数据管理：分页浏览、条件筛选、参数排序、单条修改、单条删除、范围删除。  
4. 统计分析：六参数基本统计、Pearson 相关矩阵。  
5. 预警分析：凌晨缺氧预警、盐度突变预警。  
6. 预测分析：单因素线性回归、R²、留出法 RMSE、多模型比较。  
7. 报告输出：概览、预警、统计、预测与讨论报告。  
8. 登录与权限：默认用户、扩展用户落盘、权限校验、用户导出。  
9. 备份恢复：自动/手动备份、备份列表、校验与恢复。  

## 5. 输出路径

- 清洗数据：`output/clean/`
- 报告文件：`output/reports/`
- 备份文件：`backups/`
- 用户数据：`data/auth/`

## 6. 权限说明

- 管理员：可使用全部功能。
- 访客：仅可查看概览和报告相关功能，不能执行预处理、修改/删除、备份恢复、用户管理。

## 7. 注意事项与实现边界

- 菜单层与函数层均做权限控制；访客手动输入管理员菜单编号会被直接拒绝。  
- 报告功能已可输出主要验收内容；部分“存储读写耗时”若未先执行基准对比，报告中可能缺省。  
- 本项目为课程设计实现，侧重功能完整性与稳定性，不作为生产级系统。
